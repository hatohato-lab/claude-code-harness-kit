# claude-code-harness-kit

Claude Code のルールとスキルを、人が読んで直せる精密な形で作るためのプラグインです。
あわせて、重要なファイルを1段ずつ直しながら git の差分で学ぶ「詳細学習モード」と、セッションの状況を生ログから確かめるスキルを入れています。

## 目次

1. 入っているもの（スキル7つ）
2. 入れ方（マーケットプレイスの追加とインストール）
3. 更新のしかた（使う側と作る側）
4. 注意（ルールそのものはプラグインで配れない）
5. ライセンス（MIT）

## 1. 入っているもの（スキル7つ）

| スキル | 何をするか | 呼び出す言葉 |
|---|---|---|
| ルールを作る | ルールを9段で、1段ずつ承認をもらいながら作る | 「ルールを作って」「ルール化して」 |
| スキルを作る | スキルを9段で、1段ずつ承認をもらいながら作る | 「スキルを作って」「スキル化して」 |
| 詳細学習モード | 重要なファイルを1段ずつ直し、git の差分で学ぶ | 「詳細学習モードで」 |
| セッションALL | 今日動いている全セッションの情報を1つの表にする | 「セッションALL」「全セッション」 |
| セッション情報 | このセッションの情報と、その日の作業の概要を出す | 「セッション情報」 |
| 本日作業 | このセッションで今日やった作業を表にする | 「本日作業」「今日の作業」 |
| セッション引継ぎ | 作業を選んで引き継ぎ書を作り、新しいセッションへ渡す | 「セッション引継ぎ」「引き継ぎたい」 |

ルールの書き方とスキルの書き方は、それぞれのスキルのフォルダに入っています。
セッションの4つのスキルは、生ログを読む `scripts/session_log.py`（Windows と Linux で動く Python）を使います。

## 2. 入れ方（マーケットプレイスの追加とインストール）

Claude Code で、次の2行を順に実行します。

```
/plugin marketplace add hatohato-lab/claude-code-harness-kit
```

```
/plugin install harness-kit@claude-code-harness-kit
```

## 3. 更新のしかた（使う側と作る側）

使う側は、次の1行で最新にします。

```
/plugin marketplace update claude-code-harness-kit
```

作る側は、中身を変えたら `.claude-plugin/plugin.json` の `version` を上げます。
上げないと、使う側に更新が届きません。

## 4. 注意（ルールそのものはプラグインで配れない）

Claude Code のプラグインは、`.claude/rules` のルールファイルや CLAUDE.md を配れません。

そのため、ルールの書き方は「ルールを作る」スキルに入れています。
それぞれの環境のルールは、このスキルを使って、その環境の中で作り直します。
