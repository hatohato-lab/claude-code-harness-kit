# セッションALL

生ログのフォルダを走査し、直近12時間に更新のあったセッションだけを表1つで出します。
自分1つだけを詳しく見るときは「セッション情報」スキルを使います。

## 目次

1. 情報の在りか（生ログのフォルダ）
2. 情報の取り出し（直近12時間に絞るコマンド）
3. 表の形（3列、今日発言のあるものだけ）
4. 圧縮の注意（3回以上か30MB超を名指しする）
5. 禁止（保存しない、列を増やさない）

## 1. 情報の在りか（生ログのフォルダ）

Claude Code は、会話を1セッション1ファイルで次の場所に残しています。

```
~/.claude/projects/<作業フォルダのパスの、英数字以外を - にした名前>/<セッションID>.jsonl
```

## 2. 情報の取り出し（直近12時間に絞るコマンド）

作業フォルダで、プラグインの `scripts/session_log.py` を実行します。
このスキルのフォルダから2つ上の階層にあります。`python` が無ければ `python3` を使います。

```
python <プラグインのフォルダ>/scripts/session_log.py all
```

古いログまで読むと時間がかかるので、12時間の絞り込みは外しません。

## 3. 表の形（3列、今日発言のあるものだけ）

今日の発言が1件以上あるものだけを表に出します。3列で書きます。

```
| セッション名 | 稼働 | 圧縮 / ログ |
|---|---|---|
| 設計_0921 | 09-20 17:48〜09-21 09:29 | 0回 / 7.4 MB、2,582行 |
```

今日の発言が0件のものは、表の下に1行でまとめます。

モデルが全部同じなら、表の下に1行書きます。違うものがあれば、その1つだけを名指しで書きます。

## 4. 圧縮の注意（3回以上か30MB超を名指しする）

圧縮が3回以上、またはログが30MBを超えるセッションがあれば、表の下に1行だけ書きます。

```
設計_0920 は16日間で圧縮4回。細部が要約に置き換わっている。
```

圧縮のたびに細部が消えるため、会話が通じにくくなっている可能性がある、という事実だけを書きます。
「新しくしましょうか」のような提案はしません。

## 5. 禁止（保存しない、列を増やさない）

- ファイルに保存しません。チャットに出すだけです。
- 表の前後に長い説明を書きません。表の下は最大3行です。
- 列を増やしません。3列を守ります。
- 取れなかった項目は「不明」と書きます。推測で埋めません。
