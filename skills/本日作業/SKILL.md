# 本日作業

このセッション自身の生ログだけを読み、今日の作業を時刻つきの表でチャットに出します。

## 目次

1. 対象の範囲（自分の生ログ1本だけ）
2. IDの調べ方（自分のセッションID）
3. 時刻の出し方（生ログから実時刻を取る）
4. 表の作り方（列と並び順）
5. 表の下（補足に書くもの）
6. 禁止（ほかのセッションを見ない、保存しない）
7. 日付の指定（昨日などを指定されたとき）

## 1. 対象の範囲（自分の生ログ1本だけ）

```
~/.claude/projects/<作業フォルダのパスの、英数字以外を - にした名前>/<自分のセッションID>.jsonl
```

ほかのセッションの `.jsonl` は見ません。更新時刻がいちばん新しいものを選ぶ、という選び方もしません。
別のセッションの作業まで混ざると、自分が何をしたのかが分からなくなるためです。

## 2. IDの調べ方（自分のセッションID）

1. このセッションのスクラッチパッドのパスに、セッションIDが入っています（`.../<セッションID>/scratchpad` の形）。
   会話の中で貼られた画像のパスにも、同じIDが入っていることがあります。
2. 見つからなければ、ユーザーに「このセッションIDを教えてください」と1行で聞きます。
   推測で別のファイルを開きません。

## 3. 時刻の出し方（生ログから実時刻を取る）

推定で書きません。生ログの `timestamp` を使います。
`timestamp` は UTC なので、スクリプトがこのPCの時刻帯に直して出します。

作業フォルダで、プラグインの `scripts/session_log.py` を実行します。
このスキルのフォルダから2つ上の階層にあります。`python` が無ければ `python3` を使います。

```
python <プラグインのフォルダ>/scripts/session_log.py msgs <自分のセッションID>
```

## 4. 表の作り方（列と並び順）

出た時刻を、話題の切れ目でまとめて1行にします。列は3つです。

| 時間 | 内容タイトル | 内容 |
|---|---|---|
| 18:35〜19:10 | 用語集のページ作成 | 公式の説明4本を出典に、語の定義と図2枚を作成 |

- 内容タイトルは具体的な名詞にします。「作業」「対応」「確認」のような一般語は使いません。
- 行は8行以内にまとめます。細かい往復は1つの話題にまとめます。
- 時刻は実測値です。1件しかない話題は開始時刻だけ書きます。

## 5. 表の下（補足に書くもの）

その日に作ったファイルがあれば、置き場所を単独のコードブロックで示します。
1ブロックに1つです。作っていなければ何も書きません。

## 6. 禁止（ほかのセッションを見ない、保存しない）

- ほかのセッションの生ログを開きません。
- ファイルに保存しません。チャットに出すだけです。
- 表の前後に説明や感想を書きません。
- 時刻を推定で埋めません。生ログに無ければ「時刻不明」と書きます。

## 7. 日付の指定（昨日などを指定されたとき）

「昨日」なら、日付を足して実行します。

```
python <プラグインのフォルダ>/scripts/session_log.py msgs <自分のセッションID> 2026-09-23
```

「7時から」のように時刻で絞るときは、出た行のうち、その時刻より前の行を除きます。
見る生ログは、どちらの場合も自分の1本だけです。
